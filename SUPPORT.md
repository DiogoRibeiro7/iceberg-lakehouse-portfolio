# Support

## How to get help

- Open a GitHub Issue for bugs, feature requests, or documentation gaps.
- Use the issue templates to provide reproducible details.

## Before opening an issue

1. Check existing issues and pull requests first.
2. Run local checks:
   - `python -m ruff check src tests scripts`
   - `python -m mypy src tests`
   - `python -m pytest -q`
3. Include logs, traceback, and environment details (OS, Python, Docker).

## Security

For vulnerabilities, follow the private reporting process in
[`SECURITY.md`](SECURITY.md) and do not open a public issue.
